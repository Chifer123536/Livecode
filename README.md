# Livecode — подготовка к фронтенд-собеседованиям

Два независимых проекта. Ставятся и запускаются отдельно, каждый со своим `package.json`.

| Папка | Что это | Режим работы |
|---|---|---|
| [Livecode](./Livecode) | тренажёр лайвкода: 548 задач с автотестами — JS, TypeScript, React, алгоритмы, браузер | пишешь код руками, прогресс считают тесты |
| [next-lab](./next-lab) | база Next.js App Router: 10 рабочих примеров + 20 заданий | читаешь исходник, ломаешь, чинишь, объясняешь вслух |

## Старт

```bash
cd Livecode && yarn install && yarn menu
```

`yarn menu` открывает меню тренажёра. Из терминала рабочий цикл — две команды: `yarn go` открывает
следующую нерешённую задачу, `yarn ok` проверяет её, когда написал.
Подробности в [Livecode/README.md](./Livecode/README.md), расписание занятий — в [Livecode/PLAN.md](./Livecode/PLAN.md).

Next.js трогать после того, как закрыты паки `RB`, `RH`, `RC`: вживую его писать не просят,
про него спрашивают.

```bash
cd next-lab && yarn install && yarn dev
```
