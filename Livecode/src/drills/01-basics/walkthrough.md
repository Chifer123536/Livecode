# Разборы · BAS

## BAS-01

Оператор `+` над двумя числами — арифметическое сложение.

- `a + b` :: оба операнда `number` → сумма. Если хоть один `string` — это уже склейка строк

> `sum(2, 3)`

1. a = 2, b = 3 => параметры получили значения аргументов
2. `2 + 3` => `5`

= `5`

! `'2' + 3` :: строка слева → `+` склеивает → `'23'`. Поэтому параметры типизированы `number`

## BAS-02

Чётное — значит остаток от деления на 2 равен нулю.

- `n % 2` :: остаток от деления на 2. Знак остатка берётся от n: `7 % 2` → `1`, `-3 % 2` → `-1`
- `=== 0` :: сравнение именно с нулём — у отрицательных нечётных остаток `-1`, а не `1`

> `isEven(4)`

1. `4 % 2` => `0`
2. `0 === 0` => `true`

= `true`

> `isEven(-3)`

1. `-3 % 2` => `-1`
2. `-1 === 0` => `false`

= `false`

! `isEven(0)` :: `0 % 2` → `0` → `true`
! `n % 2 === 1` :: на `-3` даёт `-1 === 1` → `false`: проверка нечётности через 1 ломается на отрицательных

## BAS-03

`Math.max` принимает сколько угодно аргументов и возвращает наибольший.

- `Math.max(a, b, c)` :: проходит аргументы слева направо и держит наибольший из просмотренных

> `max3(-5, -2, -9)`

1. первый аргумент => лидер `-5`
2. `-2 > -5` => лидер `-2`
3. `-9 > -2` — нет => лидер остаётся `-2`

= `-2`

! `Math.max()` :: без аргументов → `-Infinity`
! `Math.max(1, NaN)` :: хоть один `NaN` → результат `NaN`

## BAS-04

Отрицательное число разворачиваем минусом, неотрицательное отдаём как есть.

- `условие ? a : b` :: тернарный оператор: условие `true` → значение `a`, иначе `b`
- `-n` :: унарный минус меняет знак: `-(-7)` → `7`

> `abs(-7)`

1. `-7 < 0` => `true`
2. ветка `-n` => `-(-7)` = `7`

= `7`

> `abs(7)`

1. `7 < 0` => `false`
2. ветка `n` => `7`

= `7`

! `abs(0)` :: `0 < 0` → `false` → `0`
! `abs(-0)` :: `-0 < 0` → `false` (при сравнении -0 и 0 равны) → вернётся сам `-0`

## BAS-05

Сначала поднимаем n до нижней границы, потом опускаем до верхней.

- `Math.max(min, n)` :: n меньше min → вернёт min. Это нижняя граница
- `Math.min(max, …)` :: результат больше max → вернёт max. Это верхняя граница

> `clamp(15, 0, 10)`

1. внутренний `Math.max(0, 15)` => `15`
2. внешний `Math.min(10, 15)` => `10`

= `10`

> `clamp(-5, 0, 10)`

1. `Math.max(0, -5)` => `0`
2. `Math.min(10, 0)` => `0`

= `0`

! `clamp(5, 0, 10)` :: внутри диапазона: `Math.max(0, 5)` → 5, `Math.min(10, 5)` → `5`
! `clamp(5, 10, 0)` :: min > max: `Math.max(10, 5)` → 10, `Math.min(0, 10)` → `0` — побеждает max

## BAS-06

Сумма элементов, делённая на их количество. Пустой массив — отдельный ответ.

- `nums.reduce((acc, n) => acc + n, 0)` :: проходит массив слева направо. `acc` — накопленное, стартует с `0` (второй аргумент reduce), `n` — текущий элемент. Что вернула функция — то и становится новым `acc`
- `/ nums.length` :: сумма делится на количество
- `nums.length === 0 ? 0 : …` :: ранний ответ для пустого массива

> `average([2, 4, 9])`

1. длина 3, не 0 => идём в reduce
2. старт => `acc = 0`
3. n = 2: `0 + 2` => `acc = 2`
4. n = 4: `2 + 4` => `acc = 6`
5. n = 9: `6 + 9` => `acc = 15`
6. `15 / 3` => `5`

= `5`

! `average([])` :: длина 0 → сразу `0`. Без проверки было бы `0 / 0` → `NaN`

## BAS-07

Индекс растёт вверх: 0, 1, 2… А числа нужны вниз: n, n-1, n-2… Вычитание `n - i` разворачивает направление.

- `Array.from({ length: N }, fn)` :: создаёт массив длины N: сначала все позиции `undefined`, затем для каждого индекса от `0` до `N-1` по порядку вызывает `fn`, и её результат встаёт на эту позицию
- `(_, i) => n - i` :: `_` — старое значение позиции (там `undefined`, не нужно, поэтому подчёркивание), `i` — индекс позиции
- `Math.max(0, n)` :: длина не может быть отрицательной: при `n < 0` берётся 0

> `countdown(3)`

1. `Math.max(0, 3)` => `{ length: 3 }`
2. заготовка из length => `[undefined, undefined, undefined]`
3. i = 0: `3 - 0` = 3 => `[3, undefined, undefined]`
4. i = 1: `3 - 1` = 2 => `[3, 2, undefined]`
5. i = 2: `3 - 2` = 1 => `[3, 2, 1]`

= `[3, 2, 1]`

! `countdown(0)` :: длина 0 → позиций нет, `fn` не вызывается ни разу → `[]`
! `countdown(-2)` :: `Math.max(0, -2)` → 0 → `[]`
! `(_, i) => i` :: без вычитания получился бы обычный возрастающий `[0, 1, 2]`

## BAS-08

Длина считается заранее формулой, а каждое значение — от индекса: `from + i * step`.

- `step = 1` :: значение по умолчанию: третий аргумент не передан (`undefined`) → `step` равен 1
- `Math.ceil((to - from) / step)` :: сколько шагов помещается в полуинтервал [from, to). `ceil` добирает последний неполный шаг
- `from + i * step` :: i-й элемент: старт плюс i шагов. Ошибка float не накапливается — каждое значение считается заново

> `range(0, 10, 3)`

1. `3 <= 0` — нет, `0 >= 10` — нет => считаем дальше
2. `(10 - 0) / 3` => `3.3333333333333335`
3. `Math.ceil(3.33…)` => `length = 4`
4. i = 0: `0 + 0 * 3` => `[0]`
5. i = 1: `0 + 1 * 3` => `[0, 3]`
6. i = 2: `0 + 2 * 3` => `[0, 3, 6]`
7. i = 3: `0 + 3 * 3` => `[0, 3, 6, 9]`

= `[0, 3, 6, 9]`

> `range(1, 4)`

1. step не передан => `step = 1`
2. `Math.ceil((4 - 1) / 1)` => `length = 3`
3. i = 0, 1, 2 => `1 + 0`, `1 + 1`, `1 + 2`

= `[1, 2, 3]`

! `range(5, 5)` :: `from >= to` → `[]`
! `range(0, 5, 0)` :: `step <= 0` → `[]`. Без проверки `(5 - 0) / 0` → `Infinity`, а `Array.from({ length: Infinity })` бросает `RangeError`
! `range(0, 1, 5)` :: `Math.ceil(1 / 5)` → 1 → `[0]`

## BAS-09

Произведение чисел от 2 до n. Старт с 1 — умножение на неё ничего не меняет.

- `let result = 1` :: 1 — нейтральный элемент умножения, результат для пустого набора
- `for (let i = 2; i <= n; i++)` :: i от 2 до n включительно; начинать с 1 нет смысла
- `result *= i` :: то же, что `result = result * i`

> `factorial(5)`

1. старт => `result = 1`
2. i = 2: `1 * 2` => `result = 2`
3. i = 3: `2 * 3` => `result = 6`
4. i = 4: `6 * 4` => `result = 24`
5. i = 5: `24 * 5` => `result = 120`
6. i = 6: `6 <= 5` — нет => цикл окончен

= `120`

! `factorial(0)` :: `2 <= 0` → `false` сразу, цикл не выполняется → `1` (0! = 1)
! `factorial(1)` :: так же → `1`

## BAS-10

Проверки идут от самой строгой к общим: сначала «делится на 15», потом на 3, потом на 5.

- `i % 15 === 0` :: делится и на 3, и на 5 одновременно (15 = 3 · 5)
- `if / else if` :: срабатывает первая истинная ветка, остальные пропускаются
- `String(i)` :: число в строку — массив однородный, `string[]`

> `fizzbuzz(5)`

1. i = 1: ни одна ветка => `['1']`
2. i = 2: ни одна ветка => `['1', '2']`
3. i = 3: `3 % 3 === 0` => `['1', '2', 'Fizz']`
4. i = 4: ни одна ветка => `['1', '2', 'Fizz', '4']`
5. i = 5: `5 % 5 === 0` => `['1', '2', 'Fizz', '4', 'Buzz']`

= `['1', '2', 'Fizz', '4', 'Buzz']`

! `i = 15` :: `15 % 15 === 0` → `'FizzBuzz'`
! проверка `% 3` первой :: на 15 сработает ветка `'Fizz'`, и `'FizzBuzz'` не появится никогда

## BAS-11

Если у n есть делитель больше √n, у него есть парный делитель меньше √n. Значит, делители достаточно искать до √n.

- `Number.isInteger(n)` :: `true` только для целых: `7` → true, `7.5` → false, `NaN` → false
- `i * i <= n` :: то же, что `i <= Math.sqrt(n)`, но без вызова sqrt и без погрешности float
- `n % i === 0` :: делитель найден → число составное → сразу `return false`

> `isPrime(29)`

1. целое и ≥ 2 => идём в цикл
2. i = 2: `4 <= 29`, `29 % 2` = 1 => дальше
3. i = 3: `9 <= 29`, `29 % 3` = 2 => дальше
4. i = 4: `16 <= 29`, `29 % 4` = 1 => дальше
5. i = 5: `25 <= 29`, `29 % 5` = 4 => дальше
6. i = 6: `36 <= 29` — нет => цикл окончен, делителей нет

= `true`

> `isPrime(21)`

1. i = 2: `21 % 2` = 1 => дальше
2. i = 3: `21 % 3` = 0 => `return false`

= `false`

! `isPrime(1)` :: `1 < 2` → `false`: 1 не простое по определению
! `isPrime(2)` :: i = 2: `4 <= 2` → `false`, цикл не выполнился → `true`
! `isPrime(7.5)` :: не целое → `false`

## BAS-12

Количество цифр — это длина строки из модуля целой части.

- `Math.trunc(n)` :: отбрасывает дробную часть в сторону нуля: `-12.7` → `-12`
- `Math.abs(…)` :: убирает минус — иначе он посчитается символом
- `String(…).length` :: число символов = число цифр

> `digitCount(-12.7)`

1. `Math.trunc(-12.7)` => `-12`
2. `Math.abs(-12)` => `12`
3. `String(12)` => `'12'`
4. `'12'.length` => `2`

= `2`

! `digitCount(0)` :: `'0'.length` → `1`
! `digitCount(1e21)` :: `String(1e21)` → `'1e+21'`: начиная с 1e21 число пишется через экспоненту, и длина строки уже не число цифр

## BAS-13

Число в строку, строку в массив цифр, цифры сложить.

- `.split('')` :: строка в массив символов: `'472'` → `['4', '7', '2']`
- `.reduce((acc, d) => acc + Number(d), 0)` :: сумма с нуля. `Number(d)` превращает символ в число
- `Number(d)` :: без него `acc + d` склеит строки: `0 + '4'` → `'04'`

> `sumDigits(-472)`

1. `Math.trunc(-472)` => `-472`
2. `Math.abs(-472)` => `472`
3. `String(472)` => `'472'`
4. `.split('')` => `['4', '7', '2']`
5. d = '4': `0 + 4` => `acc = 4`
6. d = '7': `4 + 7` => `acc = 11`
7. d = '2': `11 + 2` => `acc = 13`

= `13`

! `sumDigits(0)` :: `'0'` → `['0']` → `0`

## BAS-14

Разворачиваем цифры модуля как строку, знак возвращаем в самом конце.

- `[...str]` :: спред строки — массив её символов
- `.reverse()` :: разворачивает массив на месте
- `.join('')` :: массив обратно в строку без разделителя
- `Number('0021')` :: ведущие нули отбрасываются → `21`

> `reverseNumber(-1200)`

1. `Math.abs(-1200)` => `1200`
2. `String(1200)` => `'1200'`
3. `[...'1200']` => `['1', '2', '0', '0']`
4. `.reverse()` => `['0', '0', '2', '1']`
5. `.join('')` => `'0021'`
6. `Number('0021')` => `21`
7. `-1200 < 0` => `-21`

= `-21`

! `reverseNumber(5)` :: одна цифра → `5`
! знак до разворота :: `[...'-12']` дал бы `['2', '1', '-']` → `Number('21-')` → `NaN`. Поэтому сначала `Math.abs`

## BAS-15

Алгоритм Евклида: НОД(a, b) = НОД(b, a % b). Остаток уменьшается каждый шаг; когда он станет 0, ответ — в x.

- `Math.abs(…)` :: НОД не зависит от знаков, работаем с модулями
- `[x, y] = [y, x % y]` :: справа сначала строится массив из старых x и y, потом он раскладывается по переменным — обмен без временной переменной
- `while (y !== 0)` :: крутим, пока остаток не ноль

> `gcd(48, 18)`

1. старт => `x = 48, y = 18`
2. `48 % 18` = 12 => `x = 18, y = 12`
3. `18 % 12` = 6 => `x = 12, y = 6`
4. `12 % 6` = 0 => `x = 6, y = 0`
5. `y !== 0` — нет => выход, ответ в x

= `6`

! `gcd(0, 5)` :: `0 % 5` = 0 → `x = 5, y = 0` → `5`
! `gcd(-12, 8)` :: модули 12 и 8 → `4`

## BAS-16

Високосный — делится на 4, но не на 100. Исключение из исключения — делится на 400.

- `a && b` :: `true`, только если оба `true`. Если `a` ложно, `b` не вычисляется
- `a || b` :: `true`, если хоть один `true`. Если `a` истинно, `b` не вычисляется

> `isLeapYear(1900)`

1. `1900 % 4 === 0` => `true`
2. `1900 % 100 !== 0` => `false`
3. скобка `true && false` => `false`
4. `1900 % 400` = 300 => `1900 % 400 === 0` → `false`
5. `false || false` => `false`

= `false`

> `isLeapYear(2000)`

1. `2000 % 4 === 0` => `true`
2. `2000 % 100 !== 0` => `false`, скобка `false`
3. `2000 % 400 === 0` => `true`
4. `false || true` => `true`

= `true`

! `isLeapYear(2024)` :: делится на 4, не делится на 100 → скобка `true` → правая часть `||` даже не вычисляется → `true`

## BAS-17

Сдвигаем запятую умножением на 10ⁿ, округляем до целого, сдвигаем обратно делением.

- `10 ** digits` :: возведение в степень: `10 ** 2` → `100`
- `Math.round(x)` :: к ближайшему целому; ровно `.5` — в сторону +∞: `Math.round(2.5)` → 3, `Math.round(-2.5)` → -2
- `/ factor` :: возвращаем запятую на место

> `roundTo(2.675, 2)`

1. `10 ** 2` => `factor = 100`
2. `2.675 * 100` => `267.5`
3. `Math.round(267.5)` => `268`
4. `268 / 100` => `2.68`

= `2.68`

> `roundTo(1.005, 2)`

1. `1.005 * 100` => `100.49999999999999` — 1.005 в double хранится чуть меньше
2. `Math.round(100.49…)` => `100`
3. `100 / 100` => `1`

= `1`

! `(2.675).toFixed(2)` :: `'2.67'` — toFixed смотрит на точное значение double, а не на результат умножения
! деньги :: на проде считают в целых копейках, а печатают через `Intl.NumberFormat`

## BAS-18

Доля part от total в процентах с одним знаком после запятой.

- `part / total` :: доля от 0 до 1
- `* 1000` → `Math.round` → `/ 10` :: ×100 даёт проценты, ещё ×10 — чтобы округлить до десятых, деление возвращает запятую
- `total === 0 ? 0 : …` :: защита от деления на ноль

> `percent(1, 3)`

1. `total === 0` — нет => считаем
2. `1 / 3` => `0.3333333333333333`
3. `* 1000` => `333.3333333333333`
4. `Math.round(333.33…)` => `333`
5. `333 / 10` => `33.3`

= `33.3`

! `percent(5, 0)` :: `total === 0` → `0`. Без проверки `5 / 0` → `Infinity`

## BAS-19

Каждое число — сумма двух предыдущих. Держим только последнюю пару: `prev` и `curr`.

- `let prev = 0, curr = 1` :: F(0) и F(1)
- `[prev, curr] = [curr, prev + curr]` :: пара сдвигается на шаг: старый `curr` становится `prev`, новый `curr` — их сумма. Справа всё считается по старым значениям
- `for (let i = 2; i <= n; i++)` :: каждая итерация даёт F(i)

> `fib(6)`

1. старт => `prev = 0, curr = 1`
2. i = 2 => `prev = 1, curr = 1`
3. i = 3 => `prev = 1, curr = 2`
4. i = 4 => `prev = 2, curr = 3`
5. i = 5 => `prev = 3, curr = 5`
6. i = 6 => `prev = 5, curr = 8`

= `8`

! `fib(0)` :: ранний выход → `0`
! `fib(1)` :: `2 <= 1` → цикл не выполняется → `curr = 1`

## BAS-20

Делим на 2 и собираем остатки. Остатки идут от младшего бита к старшему, поэтому каждый новый дописывается слева.

- `rest % 2` :: младший бит: 0 или 1
- `String(bit) + out` :: новый бит встаёт слева от уже собранных
- `Math.floor(rest / 2)` :: отбрасываем младший бит

> `toBinary(13)`

1. rest = 13: `13 % 2` = 1 => `out = '1'`, `rest = 6`
2. rest = 6: `6 % 2` = 0 => `out = '01'`, `rest = 3`
3. rest = 3: `3 % 2` = 1 => `out = '101'`, `rest = 1`
4. rest = 1: `1 % 2` = 1 => `out = '1101'`, `rest = 0`
5. `0 > 0` — нет => цикл окончен

= `'1101'`

! `toBinary(0)` :: `while (rest > 0)` не выполнится ни разу, поэтому ноль — отдельный ранний ответ `'0'`
! встроенно :: `(13).toString(2)` → `'1101'`

## BAS-21

Один проход: держим текущие min и max и обновляем их каждым элементом.

- `let min = nums[0], max = nums[0]` :: стартуем с первого элемента, а не с 0 — иначе на `[5, 7]` минимум был бы 0
- `if (n < min)` / `if (n > max)` :: две независимые проверки на каждом шаге

> `minMax([3, -1, 7, 2])`

1. старт => `min = 3, max = 3`
2. n = 3 => без изменений
3. n = -1: `-1 < 3` => `min = -1`
4. n = 7: `7 > 3` => `max = 7`
5. n = 2 => без изменений

= `[-1, 7]`

! `minMax([])` :: `nums[0]` не существует → ранний ответ `null`
! `Math.min(...nums)` :: на массиве в сотни тысяч элементов падает с `RangeError` — аргументов слишком много

## BAS-22

Три исхода — две проверки. Вложенный тернарник читается как `a ? x : (b ? y : z)`.

- `n > 0 ? 1 : …` :: положительное → 1
- `n < 0 ? -1 : 0` :: иначе отрицательное → -1, остальное → 0

> `sign(-4)`

1. `-4 > 0` => `false`
2. `-4 < 0` => `true` → `-1`

= `-1`

! `sign(0)` :: обе проверки ложны → `0`
! `sign(-0)` :: `-0 > 0` и `-0 < 0` ложны → `0`. А встроенный `Math.sign(-0)` вернёт `-0`

## BAS-23

Число — полный квадрат, если его корень целый.

- `n >= 0 && …` :: у отрицательных корня нет; `&&` не вычисляет правую часть, если левая ложна
- `Math.sqrt(n)` :: квадратный корень
- `Number.isInteger(x)` :: целое ли число

> `isPerfectSquare(49)`

1. `49 >= 0` => `true`
2. `Math.sqrt(49)` => `7`
3. `Number.isInteger(7)` => `true`

= `true`

> `isPerfectSquare(50)`

1. `Math.sqrt(50)` => `7.0710678118654755`
2. `Number.isInteger(7.07…)` => `false`

= `false`

! `isPerfectSquare(-4)` :: `-4 >= 0` → `false`, корень даже не считается. `Math.sqrt(-4)` дал бы `NaN`

## BAS-24

Часы — из всех секунд, минуты — из остатка часа, секунды — из остатка минуты. Каждую часть добиваем нулём до двух символов.

- `Math.floor(total / 3600)` :: целых часов
- `(total % 3600) / 60` :: остаток после часов → в минуты
- `total % 60` :: остаток после минут
- `String(v).padStart(2, '0')` :: добивает строку слева до длины 2: `'5'` → `'05'`, `'12'` остаётся

> `secondsToTime(3725)`

1. `Math.floor(3725 / 3600)` => `hours = 1`
2. `3725 % 3600` = 125 → `Math.floor(125 / 60)` => `minutes = 2`
3. `3725 % 60` => `seconds = 5`
4. pad => `'01'`, `'02'`, `'05'`

= `'01:02:05'`

! `secondsToTime(0)` :: все части 0 → `'00:00:00'`
! больше суток :: часы не обнуляются: `90000` → `'25:00:00'`
