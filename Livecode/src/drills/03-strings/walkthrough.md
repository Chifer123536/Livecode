# Разборы · STR

## STR-01

У строк нет `reverse`, у массивов есть. Строка → массив символов → разворот → обратно в строку.

- `[...text]` :: спред идёт по итератору строки — по символам Unicode. Эмодзи из двух UTF-16 единиц остаётся одним элементом
- `.reverse()` :: разворачивает массив на месте
- `.join('')` :: склеивает без разделителя

> `reverse('abc')`

1. `[...'abc']` => `['a', 'b', 'c']`
2. `.reverse()` => `['c', 'b', 'a']`
3. `.join('')` => `'cba'`

= `'cba'`

! `'👍a'.split('')` :: режет по UTF-16 единицам → `['\ud83d', '\udc4d', 'a']`, и после разворота эмодзи ломается. `[...'👍a']` → `['👍', 'a']`
! `reverse('')` :: `[]` → `''`

## STR-02

Первый символ — в верхний регистр, всё остальное — в нижний.

- `text.charAt(0)` :: первый символ; на пустой строке — `''`
- `text.slice(1)` :: всё, начиная со второго символа
- `toUpperCase` / `toLowerCase` :: возвращают новую строку, исходную не меняют

> `capitalize('пРИВЕТ')`

1. `charAt(0)` => `'п'`
2. `.toUpperCase()` => `'П'`
3. `slice(1)` => `'РИВЕТ'`
4. `.toLowerCase()` => `'ривет'`
5. склейка => `'Привет'`

= `'Привет'`

! `capitalize('')` :: `''.charAt(0)` → `''` → `''`. А `''[0]` — это `undefined`, и `undefined.toUpperCase()` бросит TypeError

## STR-03

Нижний регистр, разбить на символы, оставить гласные, посчитать.

- `VOWELS.includes(char)` :: проверка символа по строке-набору
- `[...text.toLowerCase()]` :: регистр выравнивается до проверки, поэтому в наборе только строчные

> `countVowels('Hello Мир')`

1. `toLowerCase()` => `'hello мир'`
2. символы => `h e l l o ␣ м и р`
3. гласные: `e`, `o`, `и` => 3 совпадения

= `3`

! `countVowels('')` :: `0`

## STR-04

Сначала чистим строку до сравнимого вида, потом сравниваем её с разворотом.

- `toLowerCase()` :: регистр не должен влиять
- `/[^a-zа-яё0-9]/g` :: `[^…]` — всё, что НЕ перечислено: пробелы и знаки препинания. `g` — заменить все вхождения
- `ё` в классе :: `а-я` в Unicode не включает `ё` — она стоит вне диапазона

> `isPalindrome('А роза упала на лапу Азора')`

1. `toLowerCase()` => `'а роза упала на лапу азора'`
2. убрать всё кроме букв => `'арозаупаланалапуазора'`
3. разворот => `'арозаупаланалапуазора'`
4. сравнение => равны

= `true`

! `isPalindrome('')` :: пустая строка равна своему развороту → `true`

## STR-05

Не влезает — режем до `max - 1` и добавляем многоточие: сам знак тоже занимает место.

- `text.length <= max` :: влезает — отдаём как есть
- `text.slice(0, max - 1)` :: оставляем место под `…`
- `Math.max(0, max - 1)` :: при `max = 0` не уходим в `slice(0, -1)`

> `truncate('Привет, мир', 7)`

1. `11 <= 7` — нет => режем
2. `slice(0, 6)` => `'Привет'`
3. `+ '…'` => `'Привет…'` — ровно 7 символов

= `'Привет…'`

! `truncate('abc', 3)` :: влезает → `'abc'`

## STR-06

Добавляем слова по одному, пока строка с многоточием укладывается в лимит.

- `split(/\s+/).filter(Boolean)` :: слова без пустых строк от лишних пробелов
- `next.length + 1 > max` :: `+ 1` — место под `…`
- `line ? … : truncate(text, max)` :: даже первое слово не влезло — режем по символам

> `truncateWords('Быстрая бурая лиса', 15)`

1. `18 <= 15` — нет => набираем
2. 'Быстрая': `7 + 1 <= 15` => `line = 'Быстрая'`
3. 'бурая': `'Быстрая бурая'` 13, `13 + 1 <= 15` => `line = 'Быстрая бурая'`
4. 'лиса': 18, `18 + 1 > 15` => стоп
5. `line + '…'` => `'Быстрая бурая…'`

= `'Быстрая бурая…'`

! слово длиннее лимита :: `truncateWords('Сверхдлинное', 5)` → по символам `'Свер…'`

## STR-07

Разбить на слова, каждое прогнать через `capitalize`, собрать обратно.

- `split(' ')` :: по одиночному пробелу
- `.map(capitalize)` :: функцию можно передать напрямую — map вызовет её для каждого слова
- `.join(' ')` :: обратно через пробел

> `titleCase('hello big WORLD')`

1. split => `['hello', 'big', 'WORLD']`
2. map capitalize => `['Hello', 'Big', 'World']`
3. join => `'Hello Big World'`

= `'Hello Big World'`

! `map(capitalize)` :: map передаёт ещё индекс и массив, но capitalize берёт только первый параметр — остальные игнорируются

## STR-08

Слова по любым пробелам, первая буква каждого, в верхний регистр, склеить.

- `trim()` :: пробелы по краям дали бы пустые «слова»
- `split(/\s+/)` :: один и более пробельных символов — разделитель
- `word[0]` :: первый символ слова

> `initials('  иван   сергеевич петров ')`

1. `trim()` => `'иван   сергеевич петров'`
2. `split(/\s+/)` => `['иван', 'сергеевич', 'петров']`
3. первые буквы => `['и', 'с', 'п']`
4. верхний регистр и склейка => `'ИСП'`

= `'ИСП'`

! `split(' ')` :: на двойном пробеле даёт `''`, и `''[0]` — `undefined` → TypeError на `toUpperCase`

## STR-09

Последние 4 цифры видны, остальное — группы звёздочек по 4.

- `digits.slice(-4)` :: последние четыре символа
- `Math.ceil((len - 4) / 4)` :: сколько групп закрывает скрытую часть
- `Array(n).fill('****')` :: массив из n одинаковых групп

> `maskCard('1234567812345678')`

1. `slice(-4)` => `tail = '5678'`
2. `Math.ceil((16 - 4) / 4)` => 3 группы
3. `[...Array(3).fill('****'), '5678']` => `['****', '****', '****', '5678']`
4. `join(' ')` => `'**** **** **** 5678'`

= `'**** **** **** 5678'`

! `maskCard('1234')` :: `Math.ceil(0 / 4)` = 0 групп → `'1234'`

## STR-10

Анаграммы — одинаковый набор символов. Приводим обе строки к виду «отсортированные символы» и сравниваем.

- `replace(/\s/g, '')` :: пробелы не учитываются
- `sort((x, y) => x.localeCompare(y))` :: символы по алфавиту
- `left.length === right.length` :: разная длина — точно не анаграммы

> `isAnagram('Listen', 'Silent')`

1. `'Listen'` → `'listen'` → sort => `'eilnst'`
2. `'Silent'` → `'silent'` → sort => `'eilnst'`
3. длины 6 и 6, строки равны => `true`

= `true`

! `isAnagram('ab', 'abc')` :: длины 2 и 3 → `false`

## STR-11

Убрать края, разбить по пробелам, отбросить пустое, посчитать.

- `trim()` :: иначе пробел в начале даст `''` первым элементом
- `.filter(Boolean)` :: `''.split(/\s+/)` → `['']` — один пустой элемент, его надо выкинуть

> `wordCount('  раз два   три ')`

1. `trim()` => `'раз два   три'`
2. `split(/\s+/)` => `['раз', 'два', 'три']`
3. `filter(Boolean)` => без изменений
4. `.length` => `3`

= `3`

> `wordCount('')`

1. `''.split(/\s+/)` => `['']`
2. `filter(Boolean)` => `[]`

= `0`

## STR-12

Оставляем только цифры, проверяем длину, собираем формат срезами.

- `replace(/\D/g, '')` :: `\D` — любой НЕ-цифровой символ; удаляются все
- `clean.length !== 11` :: не российский номер — возвращаем вход как есть
- `slice(a, b)` :: символы с индекса a до b, не включая b

> `formatPhone('8 (912) 345-67-89')`

1. только цифры => `'89123456789'`
2. длина 11 => форматируем
3. `clean[0]` => `'8'`
4. `slice(1, 4)` => `'912'`
5. `slice(4, 7)` => `'345'`
6. `slice(7, 9)` / `slice(9)` => `'67'` / `'89'`

= `'+8 (912) 345-67-89'`

! `formatPhone('123')` :: длина 3 → `'123'` без изменений

## STR-13

Считаем символы в Map, затем проходим её и держим лидера.

- `new Map()` :: ключ — символ, значение — счётчик. Порядок обхода = порядок первого добавления
- `counts.get(char) ?? 0` :: нет ключа → 0
- `count > bestCount` :: строго больше → из равных остаётся первый встреченный

> `mostFrequent('abbca')`

1. подсчёт => `Map { a: 2, b: 2, c: 1 }`
2. a: `2 > 0` => `best = 'a'`, 2
3. b: `2 > 2` — нет => без изменений
4. c: `1 > 2` — нет => без изменений

= `'a'`

! пробелы :: удаляются заранее `replace(/\s/g, '')` и в подсчёт не попадают
! `mostFrequent('')` :: Map пуст → `''`

## STR-14

Нижний регистр → транслитерация → всё не-латинское в дефис → схлопнуть дефисы → обрезать края.

- `TRANSLIT[char] ?? char` :: есть в словаре — заменить, нет — оставить как есть
- `/[^a-z0-9]+/g` :: подряд идущие «лишние» символы заменяются одним дефисом
- `/^-|-$/g` :: дефис в начале или в конце строки

> `slugify('Привет, мир!')`

1. `toLowerCase()` => `'привет, мир!'`
2. транслит => `'privet, mir!'`
3. лишнее в дефис => `'privet-mir-'`
4. схлопнуть дефисы => `'privet-mir-'`
5. края => `'privet-mir'`

= `'privet-mir'`

! `ъ` и `ь` :: в словаре пустая строка — исчезают: `'объём'` → `'obem'`

## STR-15

Каждую заглавную заменяем на «дефис + та же буква в нижнем регистре».

- `replace(/[A-Z]/g, fn)` :: для каждого совпадения вызывается `fn`, её результат встаёт на место совпадения
- `match => '-' + match.toLowerCase()` :: `match` — найденная буква

> `camelToKebab('backgroundColor')`

1. совпадение `'C'` => `'-c'`
2. сборка => `'background-color'`

= `'background-color'`

! `camelToKebab('HTMLParser')` :: каждая заглавная получает дефис → `'-h-t-m-l-parser'`

## STR-16

Ищем «дефис + символ», заменяем на этот символ в верхнем регистре — дефис пропадает.

- `/-([a-zа-яё0-9])/g` :: скобки — группа захвата: символ после дефиса
- `(_, char) => char.toUpperCase()` :: первый параметр — совпадение целиком (`'-c'`), второй — группа (`'c'`)

> `kebabToCamel('background-color')`

1. совпадение `'-c'`, группа `'c'` => `'C'`
2. сборка => `'backgroundColor'`

= `'backgroundColor'`

## STR-17

`padStart` добивает строку слева до нужной длины заданным символом.

- `padStart(length, char)` :: строка уже не короче `length` — вернётся без изменений
- `char = ' '` :: значение по умолчанию

> `leftPad('7', 3, '0')`

1. длина 1, нужно 3 => добавить 2 символа
2. слева `'00'` => `'007'`

= `'007'`

! `leftPad('12345', 3)` :: длиннее цели → `'12345'`

## STR-18

Пять опасных символов заменяются на HTML-сущности. Амперсанд — первым.

- `replace(/&/g, '&amp;')` :: первым, иначе следующие замены создадут `&lt;`, и его `&` превратится в `&amp;lt;`
- `/</g`, `/>/g`, `/"/g`, `/'/g` :: остальные четыре, порядок между ними не важен

> `escapeHtml('<a href="x">&</a>')`

1. `&` => `'<a href="x">&amp;</a>'`
2. `<` => `'&lt;a href="x">&amp;&lt;/a>'`
3. `>` => `'&lt;a href="x"&gt;&amp;&lt;/a&gt;'`
4. `"` => `'&lt;a href=&quot;x&quot;&gt;&amp;&lt;/a&gt;'`

= `'&lt;a href=&quot;x&quot;&gt;&amp;&lt;/a&gt;'`

! амперсанд последним :: `'<'` → `'&lt;'` → `'&amp;lt;'` — двойное экранирование

## STR-19

Каждый `{{ ключ }}` заменяется значением из объекта; нет ключа — пустая строка.

- `/\{\{\s*(\w+)\s*\}\}/g` :: `\{` — буквальная фигурная скобка, `\s*` — пробелы внутри, `(\w+)` — имя ключа в группе
- `(_, key) => String(values[key] ?? '')` :: `??` превращает отсутствующий ключ в `''`, `String` — число в строку

> `template('Привет, {{ name }}! Тебе {{age}}', { name: 'Аня', age: 20 })`

1. `{{ name }}`, key `name` => `'Аня'`
2. `{{age}}`, key `age` => `'20'`

= `'Привет, Аня! Тебе 20'`

! `template('{{x}}', {})` :: `undefined ?? ''` → `''`, в текст не попадёт `'undefined'`

## STR-20

`indexOf` с позицией старта: после каждого найденного вхождения ищем дальше, сдвинувшись на длину иглы.

- `text.indexOf(needle, from)` :: позиция первого вхождения начиная с `from`, либо `-1`
- `index + needle.length` :: вхождения не перекрываются
- `if (!needle) return 0` :: пустая игла находится в каждой позиции — цикл стал бы бесконечным

> `countSubstring('abababa', 'aba')`

1. `indexOf('aba')` => 0, `count = 1`
2. `indexOf('aba', 3)` => 4, `count = 2`
3. `indexOf('aba', 7)` => `-1` → стоп

= `2`

! с перекрытием было бы 3 :: позиции 0, 2, 4

## STR-21

Берём первое слово как кандидата и укорачиваем, пока каждое следующее слово не начнётся с него.

- `word.startsWith(prefix)` :: начинается ли слово с кандидата
- `prefix.slice(0, -1)` :: кандидат без последнего символа
- `if (!prefix) return ''` :: кандидат кончился — общего префикса нет

> `longestCommonPrefix(['flower', 'flow', 'flight'])`

1. старт => `prefix = 'flower'`
2. 'flow' не начинается с 'flower' => `'flowe'`, затем `'flow'`
3. 'flow' начинается с 'flow' => ок
4. 'flight' против 'flow' => `'flo'`, затем `'fl'`
5. 'flight' начинается с 'fl' => ок

= `'fl'`

! `longestCommonPrefix([])` :: `''`

## STR-22

Идём по символам и считаем длину текущей серии. Серия кончилась — пишем символ и, если серия длиннее 1, её длину.

- `i <= text.length` :: лишний шаг за концом: `text[length]` — `undefined`, он не равен последнему символу и закрывает последнюю серию
- `run > 1 ? символ + run : символ` :: одиночные символы без цифры

> `compress('aaabcc')`

1. i = 1, 2: совпадают с предыдущим => `run = 3`
2. i = 3: `'b' !== 'a'` => `out = 'a3'`, `run = 1`
3. i = 4: `'c' !== 'b'` => `out = 'a3b'`, `run = 1`
4. i = 5: `'c' === 'c'` => `run = 2`
5. i = 6: `undefined !== 'c'` => `out = 'a3bc2'`

= `'a3bc2'`

! `compress('')` :: ранний ответ `''`

## STR-23

Открывающую скобку кладём в стек; закрывающая обязана совпасть с вершиной стека.

- `pairs` :: закрывающая → ожидаемая открывающая
- `stack.pop()` :: снимает вершину; на пустом стеке вернёт `undefined` — это тоже несовпадение
- `char in pairs` :: закрывающая ли скобка
- `stack.length === 0` :: всё открытое закрыто

> `isBalanced('{[()]}')`

1. `{` => `stack = ['{']`
2. `[` => `['{', '[']`
3. `(` => `['{', '[', '(']`
4. `)`: pop `'('` === ожидаемая `'('` => `['{', '[']`
5. `]`: pop `'['` => `['{']`
6. `}`: pop `'{'` => `[]`
7. стек пуст => `true`

= `true`

> `isBalanced('([)]')`

1. `(`, `[` => `['(', '[']`
2. `)`: pop `'['`, ожидали `'('` => `return false`

= `false`

! `isBalanced('((')` :: в конце стек не пуст → `false`

## STR-24

Запрос превращается в регулярку без учёта регистра; найденное оборачивается в `<mark>`.

- `replace(/[.*+?^${}()|[\]\\]/g, '\\$&')` :: спецсимволы регулярок получают `\` перед собой, `$&` — найденный символ
- `new RegExp(escaped, 'gi')` :: `g` — все вхождения, `i` — без учёта регистра
- `'<mark>$&</mark>'` :: `$&` — найденный фрагмент как есть, с исходным регистром

> `highlight('Hello hello', 'hel')`

1. экранирование => `'hel'` — спецсимволов нет
2. `new RegExp('hel', 'gi')` => ищет `hel` в любом регистре
3. совпадение `'Hel'` => `'<mark>Hel</mark>'`
4. совпадение `'hel'` => `'<mark>hel</mark>'`

= `'<mark>Hel</mark>lo <mark>hel</mark>lo'`

! запрос `'('` без экранирования :: `new RegExp('(')` бросает SyntaxError

## STR-25

Номер единицы — сколько раз число делится на 1024: это логарифм по основанию 1024.

- `Math.log(x) / Math.log(1024)` :: логарифм по основанию 1024
- `Math.floor(…)` :: целая степень: 0 — байты, 1 — КБ, 2 — МБ
- `Math.min(3, …)` :: больше гигабайт единиц нет
- `Math.round(v * 100) / 100` :: два знака после запятой, хвостовые нули не появляются

> `formatBytes(1536)`

1. `log(1536) / log(1024)` => `1.058…`
2. `Math.floor` => `power = 1` (КБ)
3. `1536 / 1024` => `1.5`
4. округление => `1.5`

= `'1.5 КБ'`

> `formatBytes(5000000)`

1. `log(5000000) / log(1024)` => `2.225…` → `power = 2`
2. `5000000 / 1024 ** 2` => `4.76837158203125`
3. `Math.round(476.83…) / 100` => `4.77`

= `'4.77 МБ'`

! `formatBytes(0)` :: `Math.log(0)` = `-Infinity`, поэтому ноль — отдельный ранний ответ

## STR-26

Сначала убрать края, потом любые серии пробельных символов заменить одним пробелом.

## STR-27

Деструктуризация массива с значениями по умолчанию: недостающие части имени станут пустой строкой.

- `const [last = '', first = '', middle = ''] = …` :: элемент `undefined` → берётся значение по умолчанию

## STR-28

Копим строку, пока следующее слово влезает; не влезло — закрываем строку и начинаем новую с этого слова.

- `if (!line)` :: первое слово строки ставится без проверки
- `(line + ' ' + word).length <= width` :: влезает ли слово вместе с пробелом (в коде то же через шаблонную строку)
- `lines.push(line)` :: закрыть строку

> `wordWrap('раз два три четыре', 8)`

1. 'раз' => `line = 'раз'`
2. 'два': `'раз два'` 7 ≤ 8 => `line = 'раз два'`
3. 'три': `'раз два три'` 11 > 8 => закрыть, `line = 'три'`
4. 'четыре': `'три четыре'` 10 > 8 => закрыть, `line = 'четыре'`
5. конец => закрыть последнюю

= `['раз два', 'три', 'четыре']`
