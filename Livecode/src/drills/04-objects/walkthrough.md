# Разборы · OBJ

## OBJ-01

Идём по списку нужных ключей и копируем в новый объект только те, что реально есть в исходном.

- `keys.reduce(…, {})` :: накопитель — новый пустой объект
- `key in obj` :: есть ли ключ в объекте (включая ключи со значением `undefined`)
- `acc[key] = obj[key]` :: копируем значение

> `pick({ a: 1, b: 2, c: 3 }, ['a', 'c', 'z'])`

1. старт => `{}`
2. 'a' in obj => `{ a: 1 }`
3. 'c' in obj => `{ a: 1, c: 3 }`
4. 'z' нет => без изменений

= `{ a: 1, c: 3 }`

## OBJ-02

Объект → пары → выкинуть пары с запрещёнными ключами → обратно в объект.

- `Object.entries(obj)` :: массив пар `[ключ, значение]`
- `.filter(([key]) => !keys.includes(key))` :: деструктуризация пары в параметре: берём только ключ
- `Object.fromEntries(pairs)` :: объект из пар

> `omit({ a: 1, b: 2, c: 3 }, ['b'])`

1. entries => `[['a', 1], ['b', 2], ['c', 3]]`
2. filter => `[['a', 1], ['c', 3]]`
3. fromEntries => `{ a: 1, c: 3 }`

= `{ a: 1, c: 3 }`

! `delete copy.b` :: тоже работает, но меняет форму объекта в движке и медленнее на горячем коде

## OBJ-03

Каждая пара `[ключ, значение]` разворачивается в `[значение, ключ]`.

- `.map(([key, value]) => [value, key])` :: переставили элементы пары местами

> `invert({ a: 'x', b: 'y' })`

1. entries => `[['a', 'x'], ['b', 'y']]`
2. разворот => `[['x', 'a'], ['y', 'b']]`
3. fromEntries => `{ x: 'a', y: 'b' }`

= `{ x: 'a', y: 'b' }`

! повтор значений :: `invert({ a: 'x', b: 'x' })` → `{ x: 'b' }` — последний перетёр первый

## OBJ-04

Ключи те же, значения — результат функции.

- `[key, fn(value, key)]` :: новая пара: ключ остаётся, значение пересчитывается
- `fn(value, key)` :: ключ вторым аргументом — функция может учитывать и его

> `mapValues({ a: 1, b: 2 }, v => v * 10)`

1. entries => `[['a', 1], ['b', 2]]`
2. map => `[['a', 10], ['b', 20]]`
3. fromEntries => `{ a: 10, b: 20 }`

= `{ a: 10, b: 20 }`

## OBJ-05

Значения те же, ключи — результат функции.

- `[fn(key, value), value]` :: новая пара с пересчитанным ключом

> `mapKeys({ a: 1, b: 2 }, k => k.toUpperCase())`

1. entries => `[['a', 1], ['b', 2]]`
2. map => `[['A', 1], ['B', 2]]`
3. fromEntries => `{ A: 1, B: 2 }`

= `{ A: 1, B: 2 }`

! одинаковые новые ключи :: схлопнутся, останется последнее значение

## OBJ-06

Оставляем пары, для которых предикат вернул `true`.

- `.filter(([key, value]) => predicate(value, key))` :: пара деструктурируется, в предикат — сначала значение

> `pickBy({ a: 1, b: -2, c: 3 }, v => v > 0)`

1. a: `1 > 0` => оставить
2. b: `-2 > 0` — нет => выкинуть
3. c: `3 > 0` => оставить

= `{ a: 1, c: 3 }`

## OBJ-07

Зеркало `pickBy`: тот же фильтр с отрицанием.

- `!predicate(value, key)` :: выкидываем то, что подходит под условие

> `omitBy({ a: 1, b: -2, c: 3 }, v => v > 0)`

1. a: предикат true => выкинуть
2. b: предикат false => оставить
3. c: предикат true => выкинуть

= `{ b: -2 }`

## OBJ-08

Объект пуст, если у него нет собственных перечисляемых ключей.

- `Object.keys(obj)` :: массив собственных перечисляемых ключей
- `.length === 0` :: ключей нет

> `isEmpty({})`

1. `Object.keys({})` => `[]`
2. `0 === 0` => `true`

= `true`

> `isEmpty({ a: undefined })`

1. `Object.keys` => `['a']` — ключ есть, пусть и со значением `undefined`

= `false`

! `obj === {}` :: всегда `false`: сравниваются ссылки, а `{}` — каждый раз новый объект

## OBJ-09

Обычный объект — это объект, у которого прототип `Object.prototype` или прототипа нет вовсе.

- `typeof value !== 'object' || value === null` :: отсекает примитивы и `null` (`typeof null` — `'object'`)
- `Object.getPrototypeOf(value)` :: от чего объект унаследован
- `=== Object.prototype || === null` :: литерал `{}` или `Object.create(null)`

> `isPlainObject({ a: 1 })`

1. `typeof` => `'object'`, не null
2. прототип => `Object.prototype`

= `true`

> `isPlainObject(new Date())`

1. `typeof` => `'object'`
2. прототип => `Date.prototype` — не подходит

= `false`

! `isPlainObject([])` :: прототип `Array.prototype` → `false`
! `isPlainObject(null)` :: отсекается первой проверкой → `false`

## OBJ-10

Копируем дефолты, затем переносим из `obj` только значения, которые не `undefined`.

- `{ ...defaults }` :: неглубокая копия дефолтов
- `value !== undefined` :: явный `undefined` не должен затирать дефолт

> `withDefaults({ a: 5, b: undefined }, { a: 1, b: 2, c: 3 })`

1. копия дефолтов => `{ a: 1, b: 2, c: 3 }`
2. a = 5 => `{ a: 5, b: 2, c: 3 }`
3. b = undefined => пропуск

= `{ a: 5, b: 2, c: 3 }`

! `{ ...defaults, ...obj }` :: дал бы `b: undefined` — спред переносит и `undefined`

## OBJ-11

Каждый элемент превращается в пару `[id, элемент]`, пары — в объект.

- `list.map(item => [item.id, item])` :: ключ — id, значение — сам элемент (та же ссылка, не копия)

> `indexById([{ id: 'a', n: 1 }, { id: 'b', n: 2 }])`

1. map => `[['a', {…}], ['b', {…}]]`
2. fromEntries => `{ a: { id: 'a', n: 1 }, b: { id: 'b', n: 2 } }`

= `{ a: { id: 'a', n: 1 }, b: { id: 'b', n: 2 } }`

! одинаковые id :: остаётся последний элемент

## OBJ-12

Два представления одного списка: словарь по id для быстрого доступа и массив id для порядка.

- `byId` :: `Object.fromEntries` пар `[id, элемент]` — доступ по id за O(1)
- `allIds` :: `list.map(item => item.id)` — порядок элементов

> `normalize([{ id: 'x', v: 1 }, { id: 'y', v: 2 }])`

1. byId => `{ x: {…}, y: {…} }`
2. allIds => `['x', 'y']`

= `{ byId: { x: { id: 'x', v: 1 }, y: { id: 'y', v: 2 } }, allIds: ['x', 'y'] }`

! зачем :: обновить одну сущность — заменить одно поле `byId`, а не искать её в массиве

## OBJ-13

Идём по `allIds` в их порядке и достаём записи из `byId`; пропавшие отбрасываем.

- `allIds.map(id => byId[id])` :: порядок сохраняется
- `.filter((item): item is T => item !== undefined)` :: предикат-сужение типа: после фильтра в массиве точно `T`

> `denormalize({ byId: { x: { v: 1 } }, allIds: ['x', 'gone'] })`

1. 'x' => `{ v: 1 }`
2. 'gone' => `undefined`
3. filter => `[{ v: 1 }]`

= `[{ v: 1 }]`

## OBJ-14

Ключ есть в карте переименований — берём новое имя, нет — оставляем старое.

- `map[key] ?? key` :: новое имя или исходное

> `renameKeys({ a: 1, b: 2 }, { a: 'x' })`

1. a => `map.a` = `'x'` → `['x', 1]`
2. b => `map.b` = undefined → `['b', 2]`

= `{ x: 1, b: 2 }`

## OBJ-15

Выкидываем пары, где значение `null`, `undefined` или пустая строка.

- `value != null` :: нестрогое неравенство ловит сразу `null` и `undefined` — единственный случай, где `!=` уместнее `!==`
- `value !== ''` :: пустая строка
- `([, value])` :: пропуск первого элемента при деструктуризации — ключ не нужен

> `removeEmpty({ a: 0, b: null, c: '', d: 'x', e: undefined })`

1. a: 0 — не пустое => оставить
2. b: null => выкинуть
3. c: '' => выкинуть
4. d: 'x' => оставить
5. e: undefined => выкинуть

= `{ a: 0, d: 'x' }`

! `0` и `false` :: остаются — это значения, а не пустота

## OBJ-16

Каждая пара кодируется и склеивается через `=`, пары — через `&`. Массив даёт повтор ключа.

- `value == null` :: `null` и `undefined` пропускаются
- `Array.isArray(value) ? value : [value]` :: одиночное значение приводится к массиву из одного — дальше один код для обоих случаев
- `encodeURIComponent` :: кодирует всё, что ломает URL: кириллицу, `&`, `=`, пробел

> `toQuery({ q: 'a&b', page: 2, tags: ['x', 'y'], skip: null })`

1. q => `'q=a%26b'`
2. page => `'page=2'`
3. tags => `'tags=x'`, `'tags=y'`
4. skip: null => пропуск
5. join('&') => `'q=a%26b&page=2&tags=x&tags=y'`

= `'q=a%26b&page=2&tags=x&tags=y'`

! на проде :: `new URLSearchParams()` + `append` делает то же самое

## OBJ-17

Режем по `&`, каждую пару по `=`, раскодируем. Повтор ключа превращает значение в массив.

- `replace(/^\?/, '')` :: убрать ведущий `?`
- `const [rawKey, rawValue = ''] = pair.split('=')` :: пара без `=` получает пустое значение
- три ветки :: ключа нет → строка; уже массив → push; была строка → массив из двух

> `parseQuery('?a=1&b=2&a=3')`

1. без `?`, split => `['a=1', 'b=2', 'a=3']`
2. a=1: ключа нет => `{ a: '1' }`
3. b=2 => `{ a: '1', b: '2' }`
4. a=3: была строка => `{ a: ['1', '3'], b: '2' }`

= `{ a: ['1', '3'], b: '2' }`

! `URLSearchParams.get('a')` :: вернул бы только первое значение, все — через `getAll`

## OBJ-18

Спускаемся по ключам пути; на каждом шаге проверяем, что текущее — объект и нужный ключ в нём есть.

- `path.split('.')` :: `'a.b.c'` → `['a', 'b', 'c']`
- `key in cursor` :: наличие ключа, а не значение: `{ b: undefined }` содержит `b`
- `cursor = cursor[key]` :: шаг вглубь

> `hasPath({ a: { b: { c: 0 } } }, 'a.b.c')`

1. 'a' in корень => спуск в `{ b: {…} }`
2. 'b' in => спуск в `{ c: 0 }`
3. 'c' in => спуск в `0`
4. ключи кончились => `true`

= `true`

> `hasPath({ a: 1 }, 'a.b')`

1. 'a' in => `cursor = 1`
2. 1 — не объект => `false`

= `false`

## OBJ-19

Копируем только узлы вдоль пути: каждый уровень — новый объект со спредом старого и одним заменённым ключом.

- `const [head, ...rest] = keys` :: первый ключ и все остальные
- `rest.length === 0` :: последний ключ — применяем `updater`
- `updateIn(source[head], rest.join('.'), …)` :: рекурсивно обновляем вложенный объект
- `{ ...source, [head]: nextValue }` :: копия уровня с новым значением; соседние ветки — те же ссылки

> `updateIn({ user: { name: 'a', age: 1 }, x: 1 }, 'user.age', v => v + 1)`

1. head = 'user', rest = ['age'] => рекурсия в `{ name: 'a', age: 1 }`
2. head = 'age', rest пуст => `updater(1)` = 2
3. уровень user => `{ name: 'a', age: 2 }` — новый объект
4. корень => `{ user: {…новый}, x: 1 }` — новый объект, `x` скопирован

= `{ user: { name: 'a', age: 2 }, x: 1 }`

! структурное разделение :: ветки вне пути остаются той же ссылкой — React.memo на них не перерисует

## OBJ-20

По ключам нового объекта: значение отличается от старого — попадает в результат.

- `Object.is(a, b)` :: как `===`, но `NaN` равен `NaN`, а `0` не равен `-0`

> `objectDiff({ a: 1, b: 2 }, { a: 1, b: 3, c: 4 })`

1. a: `Object.is(1, 1)` => без изменений
2. b: `Object.is(2, 3)` — нет => `{ b: 3 }`
3. c: `Object.is(undefined, 4)` — нет => `{ b: 3, c: 4 }`

= `{ b: 3, c: 4 }`

! `NaN` в обоих :: `Object.is(NaN, NaN)` → `true`, не считается изменением. С `===` считалось бы

## OBJ-21

Рекурсивный обход с префиксом пути. Лист — всё, что не обычный объект: число, строка, массив, Date, пустой объект.

- `walk(value, prefix)` :: внутренняя функция, копит пути в `out`
- `isBranch` :: объект, не null, не массив, не Date — в него спускаемся
- `prefix ? prefix + '.' + key : key` :: у корня префикса нет, дальше путь наращивается через точку

> `deepKeys({ a: 1, b: { c: 2, d: { e: 3 } } })`

1. a — лист => `['a']`
2. b — ветка, спуск с префиксом 'b'
3. c — лист => `['a', 'b.c']`
4. d — ветка, префикс 'b.d'
5. e — лист => `['a', 'b.c', 'b.d.e']`

= `['a', 'b.c', 'b.d.e']`

! массивы :: считаются листом, иначе пути вида `'list.0.id'`

## OBJ-22

Значения объекта в массив, дальше обычная сумма через reduce.

- `Object.values(obj)` :: массив значений

> `sumValues({ a: 2, b: 3, c: 5 })`

1. values => `[2, 3, 5]`
2. reduce с 0 => `0 + 2 + 3 + 5`

= `10`

! `sumValues({})` :: `0`

## OBJ-23

Лидер — ключ; сравниваем значение текущей пары со значением лидера.

- `entries[0][0]` :: стартовый лидер — первый ключ
- `value > obj[best] ? key : best` :: строго больше → новый лидер; из равных остаётся первый

> `maxKeyByValue({ a: 3, b: 7, c: 7 })`

1. старт => `best = 'a'` (3)
2. a: `3 > 3` — нет => `'a'`
3. b: `7 > 3` => `'b'`
4. c: `7 > 7` — нет => `'b'`

= `'b'`

! `maxKeyByValue({})` :: `null`

## OBJ-24

Пары сортируются по ключу и собираются в новый объект — порядок вставки задаёт порядок ключей.

- `.sort(([a], [b]) => a.localeCompare(b))` :: сравниваем только ключи пар

> `sortKeys({ b: 1, c: 2, a: 3 })`

1. entries => `[['b', 1], ['c', 2], ['a', 3]]`
2. sort => `[['a', 3], ['b', 1], ['c', 2]]`
3. fromEntries => `{ a: 3, b: 1, c: 2 }`

= `{ a: 3, b: 1, c: 2 }`

! целочисленные ключи :: всегда идут первыми по возрастанию: `Object.keys({ b: 1, 2: 1, a: 1, 1: 1 })` → `['1', '2', 'b', 'a']`

## OBJ-25

Три ветки рекурсии: массив — обработать элементы, обычный объект — переименовать ключи и обработать значения, остальное — вернуть как есть.

- `key.replace(/_([a-z0-9])/g, (_, c) => c.toUpperCase())` :: `_x` → `X`
- `value.map(camelizeKeys)` :: элементы массива тоже могут быть объектами
- проверка прототипа :: Date, Map и экземпляры классов не разбираются на ключи

> `camelizeKeys({ user_name: 'a', items: [{ item_id: 1 }] })`

1. корень — объект => ключи по одному
2. `user_name` => `userName`, значение `'a'` как есть
3. `items` => массив, map по элементам
4. элемент `{ item_id: 1 }` => `{ itemId: 1 }`

= `{ userName: 'a', items: [{ itemId: 1 }] }`

## OBJ-26

Пары по убыванию значения; при равных значениях — по алфавиту ключа.

- `valueB - valueA` :: убывание: больший раньше
- `keyA.localeCompare(keyB)` :: при равенстве — детерминированный порядок по ключу

> `entriesByValueDesc({ b: 2, a: 2, c: 5 })`

1. c = 5 — наибольшее => первое
2. a и b по 2 => по алфавиту: a, затем b

= `[['c', 5], ['a', 2], ['b', 2]]`

## OBJ-27

Map и объект оба умеют работать с массивом пар — через него и переходят друг в друга.

- `new Map(Object.entries(obj))` :: Map из пар
- `Object.fromEntries(map)` :: fromEntries принимает любой итерируемый объект пар, Map в том числе

> `toMap({ a: 1, b: 2 })`

1. entries => `[['a', 1], ['b', 2]]`
2. new Map => `Map { a → 1, b → 2 }`

= `new Map([['a', 1], ['b', 2]])`

> `fromMap(new Map([['x', 9]]))`

1. fromEntries по парам Map => `{ x: 9 }`

= `{ x: 9 }`

## OBJ-28

Одинаковое число ключей и каждое значение совпадает по `Object.is`. Вложенное сравнивается по ссылке.

- `Object.is(a, b)` в начале :: тот же объект — сразу `true`
- `keysA.length !== keysB.length` :: разное число ключей — сразу `false`
- `hasOwnProperty.call(b, key)` :: у `b` есть такой же собственный ключ

> `shallowEqual({ a: 1, b: 'x' }, { a: 1, b: 'x' })`

1. разные ссылки => идём дальше
2. ключей 2 и 2 => сравниваем значения
3. a: `Object.is(1, 1)`, b: `Object.is('x', 'x')` => все совпали

= `true`

> `shallowEqual({ list: [1] }, { list: [1] })`

1. ключей поровну
2. list: два разных массива — `Object.is` сравнивает ссылки => не равны

= `false`

! React.memo :: сравнивает пропсы именно так — новый массив в пропсе ломает мемоизацию
